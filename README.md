# Hızlı Klavye · Speed Typing

Kelimeleri hızlı ve hatasız yaz!

Ekrandaki kelimeyi klavyeyle yaz; doğru harfler yeşile döner, yanlış tuşlar hata sayılır. Süre ilk tuşla başlar. Süre bitmeden hedef sayıda kelime yaz.

100.000 bölüm; her bölüm üretilir ve kurallara göre doğrulanır. Kelime Oyunları merkez uygulamasının oyunu; ortak motor: [kelime-motoru](https://github.com/taktemurr-ops/kelime-motoru).
